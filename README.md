# Postman API Testing

This repository contains Postman collections and resources for testing and validating REST APIs.

Quick start:
- Import the collections from the `collections/` directory into Postman.
- Run the collections using Postman or Newman to execute automated API tests.

Purpose:
- Store shareable Postman collections
- Provide example requests and expected responses
- Document how to run API tests locally
